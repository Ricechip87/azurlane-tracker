# AzurLane Tracker

내 보유함 기반 성장, 기술점수, 추가 스탯, 편성 추천을 정리하기 위한 벽람항로 개인 도구입니다.

출처: 벽람항로 각종 유저 정리 스프레드 시트들 및 위키  
(문제가 될 시 샷다 내림.)

## 현재 초점

- 내 함순이 정보: 보유, 육성, 스킬, 호감, 개장, 용골편찬, 전용 장비 상태 관리
- 육성 추천: 메인해역, 대작전, 맨땅뉴비 기준 추천표를 카드형 UI로 정리
- 개발함 추천: KR 정식 데이터 기준 1~8기 해금 조건, 부족 조건, 경험치작 후보 확인
- 기술점수 추천: 현재 보유함 기준 진영 기술점수와 획득 가능 후보 확인
- 추가 스탯작 추천: 함종별 유효 스탯의 현재 합계와 미완료 획득·120 후보 확인
- 편성 추천: 이후 확장 예정

## 사용 방식

GitHub Pages에 배포된 정적 웹 앱으로 사용합니다. 브라우저에 입력한 보유함 데이터는 LocalStorage에 저장되며, `입력 데이터`의 내보내기/가져오기로 백업합니다.

```text
https://ricechip87.github.io/azurlane-tracker/
```

## 백업 호환성

- 버전 정보가 없는 기존 브라우저 데이터와 백업 v1은 현재 사용자 데이터 스키마로 자동 변환됩니다.
- 브라우저 데이터를 변환하기 전 원본은 LocalStorage의 `azurlane-userdata-recovery`에 보관합니다.
- 현재 웹보다 높은 버전의 백업은 임의로 변환하지 않고 가져오기를 중단합니다. 이 경우 최신 웹에서 다시 가져와야 합니다.
- 등록되지 않은 함선 ID와 향후 추가 필드는 삭제하지 않고 그대로 보존합니다.

## 개발 명령

```bash
npm.cmd run test
npm.cmd run lint
npm.cmd run build
```

## 로컬 참고 자료

`참고용/` 폴더는 CSV, 원본 에셋, 임시 참고 자료를 보관하는 로컬 전용 폴더입니다. Git에는 포함하지 않습니다.
