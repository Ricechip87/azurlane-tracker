# AzurLane Tracker

내 보유함 기반 성장, 기술점수, 추가 스탯, 편성 추천을 정리하기 위한 벽람항로 개인 도구입니다.

출처: 벽람항로 각종 유저 정리 스프레드 시트들 및 위키  
(문제가 될 시 샷다 내림.)

## 현재 초점

- 내 함순이 정보: 보유, 육성, 스킬, 호감, 개장, 용골편찬, 전용 장비 상태 관리
- 육성 추천: 메인해역, 대작전, 맨땅뉴비 기준 추천표를 카드형 UI로 정리
- 개발함 추천: KR 정식 데이터 기준 1~9기 해금 조건, 부족 조건, 경험치작 후보 확인
- 기술점수 추천: 현재 보유함 기준 진영 기술점수와 획득 가능 후보 확인
- 추가 스탯작 추천: 함종별 유효 스탯의 현재 합계와 미완료 획득·120 후보 확인
- 편성 추천: 이후 확장 예정

2026-10-14 확인 기준 KR 데이터와 ALtoy에 등록된 함선 895척을 반영합니다. 기존 함선 식별자는 유지하며 소브라지텔니(META)의 최신 전투 원본을 갱신합니다. 도감 등록과 현재 획득 가능 여부를 구분하며, 소브라지텔니(META)는 10월 8일부터 월드 투어 획득 기간입니다.

킴벌리(META)는 공식 KR 10월 8일 이전 상점 편입과 현재 KR 상점 원본을 근거로 `부서진 결정` 60개·1회 교환 경로를 반영합니다. ALtoy의 이전 월드 투어 설명은 이력으로 남기고, 현재의 상시 상점 경로와 구분합니다.

[10월 8일 업데이트 완료 안내](https://cafe.naver.com/azurlanekorea/574662)의 신규 서약 스킨은 오와리 `지금, 넘쳐흐를 듯한 마음을`, 스킬라 `퓨어리 플라워리 프로미스`, 시나노 `화려한 꽃꿈의 맹약`입니다. 해당 원본 이미지는 기존 라이브러리에 확보되어 있습니다. 향후 업데이트 확인에서는 스킨과 게임 내 `시크릿즈 파일실`을 각각 캐릭터·정확한 제목·유형·KR 적용일·출처로 보고합니다. 비교 기준은 `scripts/data/kr-content-news-baseline.json`이며 유료 음성은 수집하거나 배포하지 않습니다.

육성 추천은 2026-10-11 개편된 메인해역 원본을 반영해 `메인 밀기`와 `메인 쫄작`을 별도 탭으로 구분합니다. 동일 함선이라도 용도별 등급을 섞지 않고 기함·힐러·선봉 등 원본 역할을 보존합니다. 지원항모·지원탄막 설명과 편성 예시는 출처 안내로 보존하되 임의 티어로 변환하지 않습니다.

[9월 30일 업데이트 완료 안내](https://cafe.naver.com/azurlanekorea/574581)에 따른 다음 월드 투어는 2026-10-08 00:00~2026-12-07 23:59입니다. 소브라지텔니(META)는 무료 기본 투어 보상이며, 잉그레이엄의 `미니어처라이즈 월드` 스킨은 유료 특허 투어 보상입니다. 같은 날 이전 상점에 킴벌리(META)와 미유키 스킨이 추가됩니다. 신규 스킨 8종은 9월 30일부터 10월 16일 23:59까지 판매하며, 공지 정보와 이미지 보관을 게임 내 구매 기능 또는 별도 스킨 상점 UI로 혼동하지 않습니다.

현재 이벤트 `유영 미성`은 2026-09-24 점검 후~2026-10-16 23:59이며, 보상 교환·수령은 2026-10-23 23:59까지입니다. 아즈치(1.2%)·이14(2.0%)·빅토리어스(META)(0.5%)·헤이스티(2.5%)는 한정 건조, 타이거는 진휘의 장식 교환, 호스타일은 파트너 볼 누적 보상으로 획득합니다. 빅토리어스(META)는 이벤트 교환·드롭으로도 획득할 수 있습니다. 공식 기간과 입수 방법을 우선하며, 원본 이미지가 공개됐다는 이유만으로 KR 미출시 함선을 추가하지 않습니다.

신규 `152mm 연장포 MK.XXVI` SSR/UR 두 등급은 장비 JSON 원본의 갱신 지연을 최신 KR Lua로 보완해 편성 추천의 +10 직접 능력치 후보에 반영합니다. 공식 확인된 두 등급만 보완하고, 공격·조건부 효과까지 계산하는 기능을 새로 추가한 것은 아닙니다.

[9월 17일 업데이트 완료 안내](https://cafe.naver.com/azurlanekorea/574395)에 따른 새러토가(META)의 비콘·META 동기화 기간은 2026-09-17 점검 후~2026-12-24 점검입니다. 브리스톨(META)의 한정 비콘 도전은 종료됐고, 호넷(META)은 비콘 파일에 편입됐습니다. 같은 공지에서 확인된 기존 17척을 포함한 비콘 파일 18척은 상시 특수 입수처로 정정하되, 다른 META 함선 전체로 확대하지 않습니다. 기존 17척의 9월 17일은 신규 출시일이 아니라 현행 목록 확인 기준일입니다.

인트레피드·글로스터·키타카제·U-73·탈린의 신규 전용 특수장비와, 원본 JSON 미러 지연으로 누락됐던 기존 함선 13척의 특수장비를 최신 KR Lua로 보완해 기존 정책대로 +10 직접 능력치 데이터에 반영합니다. 조건부 장비 효과 계산이나 함순이 DB의 기본 스킬을 강화 스킬로 대체하는 기능은 이번 데이터 갱신에 포함하지 않습니다. META 육성 스킬 원본도 보완해 새러토가(META)의 스킬 3개를 표시하고, 브리스톨·쾨니히스베르크(META)의 전탄발사와 엘베(META)의 대작전 패시브는 다른 META와 같은 육성 대상 기준으로 기본 스킬 목록에서 제외합니다.

이전 이벤트 `"거물"의 예고장`의 아마츠카제(SSR·중앵·구축) 소형함 한정 건조는 2026-09-24 점검으로 종료됐습니다. [9월 10일 업데이트 완료 안내](https://cafe.naver.com/azurlanekorea/574296)의 당시 기간·확률 2.0%와 BWiki로 교차 확인한 건조 시간 00:27:00은 입수 이력으로 보존합니다.

같은 업데이트로 알비트는 중형함, Z47은 소형함, U-31은 특형함 상시 건조에 편입됐습니다. ALtoy의 미갱신 건조 플래그는 `scripts/data/kr-permanent-construction.json`의 공식 KR 근거로 보완하되 원본 입수 이력과 원본 간 비교 결과는 보존합니다. Z43는 최신 KR Lua의 활성 상품 목록·무기한 교환 조건과 KR/ALtoy 입수처 설명을 근거로 `연습 상점(랜덤 출현)`에 반영합니다. 공지에 남은 `다음 점검 후` 문구와 실제 서버 교환 성공 여부는 구분하며, 근거 없는 9월 17일 개방일을 설정하지 않습니다.

이전 이벤트 `몽광의 아스트라리움`의 한정 건조·해역 드롭과 콜렛·존 로저스의 보상 수령 기간(2026-09-16 23:59까지)은 모두 종료됐습니다. 기간별 입수 이력과 [8월 27일 업데이트 완료 안내](https://cafe.naver.com/azurlanekorea/574051)의 근거는 보존합니다. DCInside 전문 보존본은 예비 출처, BWiki는 건조 시간과 PT·해역·누적 보상 세부의 교차검증 출처로 사용합니다. 출처별 역할은 `scripts/data/kr-active-events.json`에 보존합니다. 정확한 점검 시각이 공지되지 않은 종료일은 날짜 단위로 진행 중으로 취급하는 한계가 있습니다.

벨파스트 개장 판정은 위 완료 공지의 전용 개조 아이템 `메이드장의 견벽` 9월 2일 획득 개시와 [9월 2일 무점검 업데이트 안내](https://cafe.naver.com/azurlanekorea/574131)의 개조 화면·도감 오류 수정을 교차 확인해 적용합니다.

진영 표기는 인게임 필터를 따릅니다. 템페스타는 `MOT`, 페드레리아는 `LDP` 약칭을 사용하며, 원천 데이터의 영문·중문 진영명은 앱 내부 한국어 진영명으로 정규화합니다.

## 사용 방식

GitHub Pages에 배포된 정적 웹 앱으로 사용합니다. 브라우저에 입력한 보유함 데이터는 LocalStorage에 저장되며, `입력 데이터`의 내보내기/가져오기로 백업합니다.

```text
https://ricechip87.github.io/azurlane-tracker/
```

## 백업 호환성

- 버전 정보가 없는 기존 브라우저 데이터와 백업 v1은 현재 사용자 데이터 스키마로 자동 변환됩니다.
- 브라우저 데이터를 변환하기 전 원본은 LocalStorage의 `azurlane-userdata-recovery`에 보관합니다.
- 현재 웹보다 높은 버전의 백업은 임의로 변환하지 않고 가져오기를 중단합니다. 이 경우 최신 웹에서 다시 가져와야 합니다.
- 등록되지 않은 함선 ID와 향후 추가 필드는 삭제하지 않고 그대로 보존합니다.

편성 추천에는 원본 표의 해역별 예시 9개와 내 보유함 비교를 제공합니다. 첫 도전·쫄작·지원항모 예시를 선택해 배치 순서, 택1 후보, 육성용 자리, 입력된 육성 상태와 개장 필요 여부를 확인할 수 있습니다. 기존 자동 계산과는 별도 참고 기능이며, 보유 여부만으로 출격 준비 완료나 클리어 성공을 판정하지 않습니다. 16지 예시 제공은 16지 자동 계산 지원을 의미하지 않습니다.

## 개발 명령

처음 실행할 때 Node.js와 Python을 준비하고 아래 의존성을 설치합니다. Python 테스트에는 `requirements-test.txt`의 고정 버전을 사용하며, 배포 서버도 동일하게 설치합니다.

```bash
npm.cmd ci
python -m pip install -r requirements-test.txt
npm.cmd run test
npm.cmd run lint
npm.cmd run build
```

## 로컬 참고 자료

`참고용/` 폴더는 CSV, 원본 에셋, 검산 자료를 보관하는 로컬 전용 폴더이며 Git에는 포함하지 않습니다.

- `npm.cmd run sync:data-sources`: AzurLaneData, ALtoy, Fernando, 최신 KR roster·연구함·일반/특수장비·META 육성 Lua, 5개 서버 기술 Lua와 두 공개 Google Sheets를 임시 폴더에 내려받아 검증한 뒤 자동 관리 원천만 교체합니다.
- `npm.cmd run sync:reference-images`: ALtoy 함선 목록과 Fernando 이미지 원천을 비교해 없는 이미지와 하위 폴더만 추가합니다. 기존 이미지는 덮어쓰거나 삭제하지 않습니다.
- `npm.cmd run sync:skins`: Fernando의 최신 함선별 스킨 메타데이터를 기준으로 플레이어 함선의 기본·전체 스킨 렌더와 공용 `background`/`background2` 이미지 누락분을 각각 `참고용/AzurLane/images/skin/<skinId>/`, `참고용/AzurLane/images/background/`에 원자적으로 추가합니다. 공용 배경은 메타데이터 URL 경로로 중복을 제거하고, 오디오인 `bgm` 필드는 이미지 동기화에서 제외해 보고서에만 집계합니다. 정상인 기존 파일과 메타데이터에 없는 수동 자산은 보존하고, 손상되었거나 확장자와 실제 포맷이 일치하지 않는 선언 자산은 원본으로 자동 교체하며, `public/`에는 복사하지 않습니다.
- `npm.cmd run audit:data-sources`: 위 데이터·이미지 동기화를 먼저 실행한 뒤 앱 데이터와 교차 검증 보고서를 만듭니다.
- `npm.cmd run audit:data-sources:local`: 네트워크 갱신 없이 마지막으로 동기화한 참고 자료만 다시 검사합니다.
- `npm.cmd run refresh:data`: 원천과 이미지를 갱신한 뒤 캐릭터·기술점수·육성·개발함·입수처 JSON 및 필요한 카드 아트를 다시 만들고 최종 감사를 실행합니다.
- `npm.cmd run sync:recommendation-art`: 육성·개발함·추가 스탯 추천에 필요한 세로형 카드 이미지를 참고용 원천에서 동기화합니다.

동기화는 `검산용.json`, 이미지 폴더, 자동 관리 목록 밖의 사용자 자료를 보존합니다. 원격 파일을 전부 검증하기 전에는 기존 자료를 교체하지 않습니다. 정상 롤백이 확인된 임시 파일과 교체용 백업은 정리하며, 복원 자체가 실패하면 수동 복구를 위해 백업을 보존합니다.

신규 업데이트를 처음 확인할 때는 `npm.cmd run audit:data-sources`를 사용합니다. 이 명령은 앱 데이터를 섣불리 재생성하지 않고 원격 함선·스킨 메타데이터와 선언된 플레이어 함선 스킨 렌더·공용 배경을 먼저 수집해 차이를 보고합니다. ALtoy와 전투 데이터까지 준비된 것이 확인되면 `npm.cmd run refresh:data`로 앱 JSON을 갱신합니다. 메인 CSV가 KR보다 앞서 갱신돼도 ALtoy에 확인되지 않은 신규 행은 자동 편입하지 않으며, 기존 유효 식별자가 사라지는 갱신은 저장 전에 중단합니다. 대용량 원본은 Git에서 제외된 `참고용/`에만 보관하고 GitHub Pages에는 현재 화면에서 사용하는 아이콘과 카드 아트만 포함합니다.

2026-10-14 확인 기준 원본 라이브러리는 고유 스킨 2,467종, 선언 이미지 16,171개(공용 배경 138개 포함)입니다. 현재 라이브러리에 이번 신규 스킨과 소브라지텔니(META) 원본 이미지가 모두 확보되어 있습니다. 이미 확보한 정상 원본을 다시 변환하거나 중복 저장하지 않으며, 예고 이미지 확보와 실제 획득 개시일을 구분합니다.
