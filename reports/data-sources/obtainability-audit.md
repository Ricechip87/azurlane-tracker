# KR 입수 상태 전수조사

검토일: 2026-07-19
표시 범위: 앱의 KR 확인 함선 870명

## 결과

- 상시 획득: 600명
- 현재 이벤트: 5명
- 복각 대기: 176명
- 콜라보 복각 미정: 89명
- 미확인: 0명

기존 `한정/복각 대기` 중 54명은 ALtoy 상시 건조 플래그, 메인 해역/작전문서 드랍, 상시 상점, KR 상시편입 기록을 통해 상시 획득으로 재분류했다.

추가 검증에서 KR `month_shop_template`의 월별 상품과 `activity_shop_template`의 함선 상품을 연결해 코어 월간 교환 함선 25명을 확인했다. 이 중 기존 판정이 누락한 인디펜던스, 꼬마 샌디에이고, 푸보, 로열 포춘, 하이티엔, 하이치, 우라나미 7명을 상시 획득으로 추가 보정했다.

KR 상시편입 기록으로 추가 보정한 5명은 이카로스, 미유키, Z24, 에밀 베르탱, 어드벤처 갤리다. 칭송받는자 6명은 수동 `입수 못함` 예외를 제거하고 다른 과거 콜라보와 동일하게 `콜라보 복각 미정`으로 통합했다.

현재 이벤트 판정은 셰르부르, 아로망슈, 랑트레피드, 브리스톨(META), 쾨니히스베르크(META)에 적용했다. META전 종료일은 시즌 교체 주기를 바탕으로 한 운영값이므로 다음 데이터 갱신 때 실제 KR 일정과 다시 확인한다.

기존 교차검증에서 CN 상시·KR 미확인으로 보였던 꼬마 샌디에이고, 인디펜던스, 푸보, 로열 포춘은 KR 코어 월간 원본으로 상시 획득이 확인됐다. 에마누엘레 페사노만 현재 확인한 KR 상시 입수처가 없어 `복각 대기`를 유지했다.

## 영향 조사와 수정

- 육성 추천: 미보유 `쉬움`만 허용하던 규칙에 현재 KR 이벤트를 추가하고, 복각 대기/콜라보 대기는 제외한다.
- 개발함 추천: 과거에는 `추천 제외`만 차단해 일반 한정·콜라보 함선이 후보로 섞였다. 미보유 함선은 상시 획득 또는 현재 이벤트만 후보로 허용한다.
- 정렬: 보유 상태와 남은 단계 우선 규칙은 유지하고, 미보유는 상시 쉬움 → 현재 이벤트 → 상시 보통 → 상시 어려움 순으로 정렬한다.
- 카드/팝업: 저격 난이도로 오해할 수 있는 `쉬움/보통` 문구를 노출하지 않고 `상시 획득`, `현재 이벤트`, `복각 대기`, `콜라보 복각 미정`만 표시한다.
- 입수처: 상시편입 함선은 현재 상시 건조·상점·해역·작전문서 입수처와 과거 이벤트 입수처를 구분해 함께 표시한다.
- 검토 리포트: 상태별 집계를 추가한다.
- 사용자 백업: 입수 상태는 사용자 백업 JSON에 저장되는 필드가 아니므로 가져오기/내보내기 스키마 영향이 없다.
