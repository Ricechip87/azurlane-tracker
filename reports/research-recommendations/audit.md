# 개발함 추천 데이터 검수

검수일: 2026-07-18

## 결론

검수 결과를 바탕으로 KR 게임 JSON에 정식 수록된 1~8기 연구함 42명의 개발함 추천 기능을 구현했다. 해금 가능 여부, 부족 조건, 경험치작 보유함, 물자강화 가능 여부를 표시한다.

9기는 공개 시트의 잠정 정보로 먼저 넣지 않는다. KR 기본 캐릭터·개발 임무 데이터에 정식 편입되면 gid, 이미지, 해금 조건을 교차검증한 뒤 추가한다.

## 검수 당시 확인된 문제와 처리 결과

### 1. 개발함 추천 탭 미구현 — 해결

- 전용 추출 데이터, 추천 계산 함수, 카드·상세 UI와 회귀 테스트를 추가했다.
- 획득한 함선은 완료, 미획득 함선은 해금 가능/해금 필요로 구분한다.

### 2. 9기 5명 미수록 — KR 정식 편입까지 보류

공식 9기 명단과 공개 시트의 한국어 표기는 다음과 같다.

| 구분 | 한국어 표기 | 함종 | 주요 해금 조건 |
|---|---|---|---|
| DR | 막스 임멜만 | 철혈 항모 | 철혈 기술점수 1050 |
| PR | 타카하시 | 중앵 경순 | 중앵 기술점수 1000 |
| DR | 발파라이소 | 신규 진영 전함 | 유니온 950, 로열 1000 |
| PR | 던컨 | 로열 순전 | 로열 기술점수 700 |
| PR | 오라주 | 아이리스 구축 | 아이리스 기술점수 280 |

공식 중국어 명단은 발파라이소·막시밀리안 임멜만이 결전방안(DR), 던컨·타카하시·오라주가 최고방안(PR)임을 확인해 준다.

현재 앱·ALtoy·Fernando2603·AzurLaneData 공개 원천은 모두 1~8기 42명까지만 제공한다. 따라서 9기의 gid, skin ID, 스탯, 기술점수, 게임 개발 임무 원문은 기존 자동 최신화 경로만으로 아직 확정할 수 없다.

### 3. 진영 기술점수 계산 범위 부족 — 해결

현재 `fleetTech.js`는 유니온·로열·중앵·철혈 4대 진영만 계산한다. 개발함 해금에는 다음 진영도 필요하다.

- 동황
- 사르데냐
- 노스 유니온
- 아이리스
- 비시아
- 튤리퍼
- 둘 이상의 진영을 동시에 요구하는 복합 조건

개발함 추천에서는 모든 진영의 기술점수를 같은 규칙으로 계산해야 한다.

### 4. 1기 해금 조건은 기술점수가 아님 — 해결

1기 일부 함선은 진영 기술점수가 아니라 특정 진영의 전열·후열 등록 수를 요구한다. 기술점수 계산만 재사용하면 잘못된 해금 판정이 나온다.

### 5. 개발 진행 상태가 없음 — 1차 구현 범위 명시

현재 사용자 데이터로 알 수 있는 것은 함선의 미획득/획득/육성 상태다. 다음 상태는 기록하지 않는다.

- 현재 개발 중인 대상
- 개발 임무 진행도
- 강화 레벨 30 달성 여부
- 용골편찬 완료 여부
- 물자강화 사용 여부

1차 구현에서는 `획득=개발 완료`, `미획득=개발 후보`까지만 안전하게 판정할 수 있다. 세부 진행 상태를 추천에 반영하려면 별도 입력 필드가 필요하다.

### 6. 물자강화·장비 시점 중 일부는 예상값 — 게임 데이터만 표시

공개 시트는 2026-07-06 기준 1~5기 물자강화와 장비 상시화를 완료된 정보로 적고 있다. 6기 이후의 2027~2030년 시점은 일부가 예상으로 명시되어 있으므로 사실값과 예상값을 분리해서 표시해야 한다.

AzurLaneData의 `is_pursuing` 값은 현재 1~5기 전원, 6기의 시만토·펠릭스 슐츠·플랑드르에 활성화되어 있어 실제 물자강화 가능 여부 검증에 사용할 수 있다.

## 권장 데이터 구조

개발함별로 다음 필드를 생성한다.

```json
{
  "id": "P042",
  "gid": 119901,
  "name": "하우덴 리우",
  "generation": 8,
  "planRarity": "DR",
  "unlockRequirements": [],
  "xpPhases": [],
  "coinStrengthening": {
    "available": false,
    "source": "game-data"
  },
  "sourceStatus": "verified"
}
```

9기는 KR 정식 게임 JSON이 나온 뒤 같은 구조로 추가하고 gid·skin ID·임무 데이터를 교차검증한다.

## 권장 추천 방식

1. 미획득 개발함만 후보로 둔다.
2. 구글 시트의 운용 방침에 따라 최신 기수를 우선하되 절대적인 성능 순위로 표현하지 않는다.
3. 현재 기술점수/등록 수로 즉시 해금 가능한 함선을 먼저 표시한다.
4. 해금이 부족하면 남은 점수와 해당 진영 기술점수 후보를 연결한다.
5. 1·2차 경험치작에 사용할 수 있는 현재 보유 함선을 진영과 전열/후열 조건으로 보여준다.
6. 물자강화 가능한 이전 기수는 최신 기수 연구와 병행 가능한 대상으로 안내한다.
7. 예상 시점은 `예상` 배지를 붙이고 정식 게임 데이터와 섞지 않는다.
